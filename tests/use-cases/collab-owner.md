# Use case: the owner stays in control

1. Zach comments `/collab pause` on the PR in the browser. The next `collab next`, `wait` or mutating command by any agent reads comments newer than the ledger's `lastCommentId`. It sees that the author has write access and applies the pause. Agents get `paused` and exit 4. The dashboard shows the pause with a link to the comment. Only comments written after the collab started count: when Zach closes a collab with `--purge` and starts a new one on the same PR, the old `/collab pause` and `/collab cancel T2` comments don't touch it.
2. A comment `/collab pause` from someone with read-only access is ignored.
3. A comment `/collab resume` is ignored: comments can only stop work. Zach runs `collab resume` in his own terminal instead.
4. Codex runs `collab block T3 --reason "LRU or TTL?" --owner`. The dashboard goes Blocked, and a single "Needs owner" comment is posted. Zach runs `collab decide T3 "TTL"`, which unblocks T3 and posts the decision. Codex can't read the PR, so its next `collab next` prints Zach's answer with the task. If Codex later asks a second question on T3, that question gets its own "Needs owner" comment (repeating the same question doesn't post another), and the first answer is no longer shown as if it answered it.
5. Inside an agent session, where `CLAUDECODE`, `CODEX_THREAD_ID` or `COLLAB_AGENT` is set, `collab resume`, `decide`, `waive-review` and `close` are refused with "owner-only command; run it in your own terminal".
6. While the collab is paused, `collab push` is refused before it pushes the branch or opens a sub-PR, so nothing on GitHub gets ahead of the ledger. If a sub-PR for the task's branch is already open but missing from the ledger, the next push reuses it instead of opening a duplicate.
7. Zach runs `collab close` when he's done. It archives the ledger, history included, to `~/.collab/archive/`. The ledger ref stays, marked closed: agents still in their loop get `closed` and exit 4, and `collab join` refuses to start over. `collab close --purge` deletes the ref.
